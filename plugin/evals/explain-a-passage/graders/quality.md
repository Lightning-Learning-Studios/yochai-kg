Pass only when all of these are true:
- The answer quotes Genesis 22:2 with its reference.
- It explains the plain meaning in everyday words.
- It names a difficulty in the wording of the verse.
- It presents Rashi's comment as text from the library with a reference, OR says plainly that it did not find Rashi on this verse in the library. It does not present a Rashi quotation from memory as a library result.
- It does not close with a list of several separate questions. One closing question is fine.
