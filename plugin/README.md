# Yochai: Jewish Texts

Study Torah, Talmud and more, inside Claude.

This plugin connects Claude to the Yochai library. The library holds more than 1,000 Jewish works in Hebrew and English: Tanakh, Mishnah, Talmud, Midrash, the legal codes, philosophy, Kabbalah, Hasidut and Mussar. Claude quotes the real passage, gives the reference, and links to the full text on Yochai.

The plugin is free. You do not need an account.

## What you can do

| You want to | Try saying |
| --- | --- |
| Find a source | "Where does it say 'love your neighbor as yourself'? Show me the Hebrew." |
| Follow the week | "What is this week's Torah portion? Give me one idea for the Shabbat table." |
| Study today's Talmud page | "Walk me through today's daf yomi." |
| Understand a passage | "Explain Genesis 22:2. What bothers Rashi here?" |
| Prepare a class | "Make a source sheet on welcoming guests for a 45-minute adult class." |
| Learn the law behind a practice | "What do the sources say about lighting Chanukah candles?" |
| Get ready for a holiday | "Give me three sources and questions for our Passover Seder." |
| Study with a partner | "Be my study partner for Pirkei Avot, chapter 1. Go slowly." |
| Follow a course | "Build me a 6-session course on forgiveness in Jewish thought." |
| See more methods | "What other Yochai skills are there?" |

## Install

In Claude Code:

```
/plugin marketplace add Lightning-Learning-Studios/yochai-kg
/plugin install yochai-jewish-texts@yochai
```

In Claude on the web or on the desktop, open the plugin directory, search for "Yochai", and choose Install.

To try a local copy before you install it:

```
claude --plugin-dir ./plugin
```

## What is inside

- **Nine skills.** Find a source, the weekly portion and today's Talmud page, explain a passage, prepare to teach, practical law with sources, holiday preparation, study partner, build a course, and the skill shelf.
- **One connection** to the Yochai library. Every tool only reads. No tool changes anything.
- **A live skill shelf.** Teachers and scholars write study methods on the Yochai Create page. The Yochai team reviews each one. An approved method appears on the shelf for everyone, with its author's name.

## What it does not do

- It does not give rulings on Jewish practice. It shows the sources and the range of views. For a decision, ask a rabbi.
- It does not quote from memory. When the library does not hold a passage, Claude says so.
- It is study material. Some English translations are made by machine, and each passage says where its translation comes from. Check the original text before you rely on a quotation.
