# Terms of Use for Yochai: Jewish Texts

Last updated: November 20, 2026 (draft)

Yochai: Jewish Texts is a free study tool from Lightning Studios, built with Gratz College and supported by the Maimonides Fund. When you use it, you agree to these terms.

## 1. A study aid

The plugin helps you find and read Jewish texts. It is not a rabbinic authority. It gives no rulings on Jewish law. For a personal decision, ask a rabbi or another qualified teacher.

The plugin finds passages with automated search. Some summaries, concept descriptions and translations are made by machine and can be wrong. Check important passages against the primary text. Each result links to its source.

## 2. The texts

Yochai shows texts and translations under its display licences, with credit to the source of each translation. You may read, quote and teach from what the plugin shows, with that credit. The texts and translations belong to their authors, translators and publishers.

## 3. Fair use

The plugin is free. To keep it fast for all users, the server limits the number of requests from one network address.

You agree that you will not:

- copy the library in bulk, or build a copy of it from the plugin's results;
- use automated tools to get around the limits;
- resell the plugin's results or present the texts as your own work;

We can limit or block use that breaks these terms.
