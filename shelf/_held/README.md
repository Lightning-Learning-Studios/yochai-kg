# Held skills

A skill waits here when its author has not yet agreed in writing to share it in the public plugin.

The server does not read this folder. No assistant can list or load a skill that is here.

When the author agrees, a person moves the skill folder to `shelf/community/` in a pull request and records the consent in that pull request.

Do not put a skill here unless its author has agreed that the text may be in this public repository. Until then, keep the text in a private place.
